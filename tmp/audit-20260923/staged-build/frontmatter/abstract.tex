\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Digital education often relies on disparate platforms for communication,
content delivery, live teaching, and assessment. Although these tools may be
individually effective, their separation creates fragmented workflows,
repeated context switching, and weaker institutional continuity. This thesis
presents EduVerse, an integrated educational web platform with a mobile
companion application, designed to consolidate these activities within a
governed, role-based environment for administrators, teachers, and students.

EduVerse provides a comprehensive suite of learning management features,
including content distribution, assessments, real-time collaboration via live
sessions and whiteboards, an AI agent, and an integrated browser-based IDE.
The web platform is built using Next.js, React, and TypeScript, integrating
Supabase for authentication and relational data, AWS S3 for file storage,
LiveKit for real-time communication, and OpenRouter for AI services.
EduVerse Mobile---developed with Expo and React Native---extends the platform
through selected high-frequency workflows, including class overviews, chat,
notifications, materials, organization switching, and basic live-session
participation.

The evaluation combines automated logic-level testing with engineering
verification during development. The automated suite completed with 76 passed
tests, 0 failures, and 105 assertions across 10 test files, while shared API
reuse and modular feature enablement support consistent role-based academic
workflows across the implemented clients. Consequently, EduVerse contributes a
governed, extensible model for reducing fragmentation in digital learning
environments.
