\chapter*{Conclusion}\label{chap:conclusion}
\addcontentsline{toc}{chapter}{Conclusion}

EduVerse was developed to address a clear problem in contemporary digital
education: closely related academic workflows are often divided across separate
platforms, even though students, teachers, and institutions need them to work
together. This thesis has shown how EduVerse responds to that problem through a
multi-organization, role-based educational environment that brings classes,
materials, communication, assessment, live collaboration, AI support, and
coding practice into one governed platform.

The implemented system demonstrates that this integration can be achieved in a
structured and technically credible way. The web platform provides the primary
operational environment through shared protected APIs, role-aware access
control, Supabase-backed data services, S3-based file storage, LiveKit-based
live sessions, and configurable feature availability. Alongside it, the mobile
companion application extends selected high-frequency workflows such as class
summaries, notifications, materials, chat, organization switching, and basic
live-session participation, while remaining intentionally narrower in scope
than the web platform.

Taken together, the project contributes a coherent model for reducing
fragmentation in digital learning environments without sacrificing governance,
extensibility, or academic control. Further refinement should focus on
scalability, broader user feedback, and continued usability improvement, but
the current implementation already establishes EduVerse as a meaningful and
practical foundation for an integrated educational platform.
